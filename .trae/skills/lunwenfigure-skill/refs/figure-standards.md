## 一、配图核心理念

### 1. 先画图，再写论文
写论文之前先画流程图，理清论文的"骨架"和逻辑结构。图是论文的指导文件。

### 2. 论文 = 文字 + 插图
90%的科研劳动通过配图来体现。配图质量直接影响论文的引用率和审稿人印象。

### 3. 20%细节决定80%质量
80%的人只是"做出来"，20%的人讲究细节。愿不愿意花这20%的精力，决定了论文能走多远。

### 4. 审稿人视角
审稿人拿到论文：先看标题，再看图片。图片是建立第一印象的关键。

## 二、三大类配图标准

### 2.1 实验图（Experimental Figures）

| 项目 | 标准 |
|------|------|
| 内容 | 展示实验现象的原始图像 |
| 核心原则 | **紧扣主题**，不画蛇添足 |
| 处理工具 | Photoshop（首选）、PowerPoint、Imagine Pro（备选） |
| 常用操作 | 裁剪、修补、抠图、调色、上色 |
| 老师原话 | "你表现火焰形态就可以了，表现暖气干什么呢？" |

### 2.2 数据图（Data Figures）

| 项目 | 标准 |
|------|------|
| 内容 | 实验数据的可视化展示 |
| 核心原则 | **必须调整**字体、字号、颜色、线条粗细 |
| 推荐工具 | GraphPad（首选，免费绿色）、Excel（需二次创作）、Origin |
| 质量标准 | 达到"赏心悦目"级别 |
| 当前趋势 | AI工具普及，论文配图水平普遍提高，不美化会被淘汰 |
| 老师原话 | "什么都没有调，自己字号都没有调，线的颜色也没有调，粗细也没有调，这样就发表。看的人能多吗？" |

### 2.3 示意图（Schematic Diagrams）

| 项目 | 标准 |
|------|------|
| 内容 | 实验系统、工作原理、概念模型 |
| 核心原则 | **用心画**，细节体现质量 |
| 推荐工具 | Illustrator（首选）、PPT（备选）、3D Max（三维模型） |
| 约束 | 同样一套系统，用心画和不用心画的差别巨大 |
| 老师原话 | "同样的一套实验系统，你用心的画了和你没用心画的差别" |

## 三、软件工具矩阵与分工

| 软件 | 适用场景 | 地位 | 核心功能 |
|------|----------|------|----------|
| **Photoshop (PS)** | 实验图 | 首选 | 裁剪、修补、抠图、调色、上色 |
| **Illustrator (AI)** | 示意图 | 首选 | 排版、写字、画线、标注、绘图 |
| **GraphPad** | 数据图 | 首选推荐 | 比Excel/Origin美观，免费绿色 |
| **PowerPoint** | 示意图 | 备选 | 图形插入、画线 |
| **Excel** | 数据图 | 基础工具 | 需二次创作 |
| **Origin** | 数据图 | 传统工具 | 需手动美化 |
| **3D Max** | 三维模型 | 专项工具 | 有机物/分子/原子等球体模型 |

### PS vs AI 分工
- **Photoshop**：裁剪、修补、抠图、调色、上色
- **Illustrator**：排版、写字、画线、标注、绘图
- 两者经常成对使用

## 四、配图质量检查清单

### 基础规范
- [ ] 字体是否统一（全文所有图使用相同字体族）
- [ ] 字号是否合适（与正文字号匹配，不可过小/过大）
- [ ] 线条粗细是否一致（同类型线条使用相同粗度）
- [ ] 颜色搭配是否协调（不刺眼、色盲友好、打印友好）

### 内容相关
- [ ] 图是否紧扣主题（无无关元素）
- [ ] 图与正文内容是否对应
- [ ] 图注/标注是否清晰完整
- [ ] 图例是否清晰可辨

### 数据呈现
- [ ] 坐标轴标签和单位是否完整
- [ ] 是否有必要的误差分析
- [ ] 数据点/趋势是否清晰可见

### 美观度
- [ ] 整体视觉效果是否专业
- [ ] 多面板图是否对齐、间距合理
- [ ] 色彩使用是否科学

### 学术规范
- [ ] 无篡改、拼接等学术不端
- [ ] 实验图无过度美化掩盖原始数据

## 五、老师原话弹药库（绘图指导用）

### 核心理念
- "论文才是你的科研。对科研考察的永远是成果。"
- "论文是什么？就是文字和插图。"
- "论文的目的，绝不只是让人看懂。"
- "审稿人先看标题，再看图片。我觉得是非常重要的。"

### 质量警示
- "什么都没有调，自己字号都没有调，线的颜色也没有调，粗细也没有调，这样就发表。看的人能多吗？"
- "现在AI这么多工具，你随便下一个论文去看它的图，都特别的赏心悦目。到到这个级别了。"
- "这个都达不到一个赏心悦目，是不是？"

### 细节决定质量
- "80%的人做科研，我们只是把它做出来。20%的做科研，我们讲究的是细节。"
- "由左边这个到右边这个，其实就是20%做出来的。细节就是质量。"
- "愿不愿意花这20%的精力去做这个事，就决定了你这个论文能走多远。"

### 关于工具
- "Excel用好了也很漂亮，关键是你会不会对它进行二次的创作。"
- "GraphPad比Excel和Origin我觉得出来的图会更好看。而且它是一个绿色的软件，不收费的。"
- "高质量的图像能够反映高质量的研究小组。"

### 关于主题相关性
- "你表现火焰形态就可以了，表现暖气干什么呢？"

## 六、国际背景

- **5大国际出版社**：Elsevier（荷兰）、Springer（德国）、Nature（英国）、Francis（英国）、Wiley（美国）、Sage（瑞士）
- **国外课题组配置**：每个课题组专门配有科研图像处理专家
- **中国论文差距**：与4国比引入率不高，论文图片质量差是重要原因
