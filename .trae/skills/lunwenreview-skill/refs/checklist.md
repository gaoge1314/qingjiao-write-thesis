# 各章节审稿检查标准手册

> 来源：老师课件（课件.txt）+ 课堂录音（天巍.docx）
> 用途：供 lunwenreview-skill 审稿时逐章对照检查

---

## 审稿检查顺序

严格按照老师推荐的论文写作/修改顺序逐章会诊：

> **方法论 → 结果与讨论 → 结论 → 引言 → 摘要/标题/关键词 → 致谢/参考文献**

---

## 一、方法论（Methodology）

### 要素清单（检查是否都覆盖了）

- [ ] **研究类型介绍**：清楚地介绍论文的研究类型（实验研究/数值模拟/文献数据等）
- [ ] **数据收集的方法**：原则为越详细越好，最好是其他人能重复出来
- [ ] **数据分析的办法**：说明具体的方法和步骤（如 Arrhenius equation）
- [ ] **利用的工具和方法**：实验器材/软件工具（如 FLUENT, Origin）
- [ ] **选取这些方法的原因**：每个工具和方法都要解释"为什么选这个"

### 常见错误（毒舌批判靶点）

- ❌ 没有结合论文的研究目标 → 不能突出研究方法的创新性
- ❌ 没有考虑潜在读者（目标期刊） → 介绍太细或太粗
- ❌ 忽略了具体原因的描述 → 审稿专家通常会追问"为什么"
- ❌ 在方法论部分介绍论文的局限 → 局限应放在结论尾部
- ❌ 时态混乱 → 实验步骤用过去式，介绍方法用现在式

### Checklist（7项）

1. 包含研究类型介绍、数据收集方法、数据分析办法、工具和方法以及选择原因
2. 描述实验过程使用过去式，介绍方法时使用现在式
3. 写作密切结合论文的总体研究目标
4. 介绍方法时考虑目标期刊而进行不同程度的介绍
5. 论文的局限不在 Methodology 介绍（放在结论尾部）
6. 尽量用生动的原理图来介绍方法
7. 从创新以及正面克服挑战的角度来撰写

### 进阶检查点

- 是否从克服挑战的角度写？（"It is quite challenging to... We developed..."）
- 初稿阶段是否只机械罗列步骤，缺乏挑战意识？

---

## 二、结果与讨论（Results & Discussion）

### 要素清单

- [ ] **突出数据分析之后得到的结论**：直接讲出数据反映的结论，不是让读者去猜
- [ ] **中心句+数据支持**：先给结论，再展示数据证明
- [ ] **紧扣论文的科学问题**：避免离题，可以忽略非重点的结论
- [ ] **四层结构**（推荐写法）：
  1. 介绍研究结论
  2. 展示数据
  3. 深化研究（分析背后原因/机制）
  4. 阐明研究意义

### 常见错误（毒舌批判靶点）

- ❌ 描述没有重点 → 只对图表进行简单描述，缺乏强弱分析以及概括结论
- ❌ 重复描述图表内容 → 削弱了重点结论，使论文看起来比较累赘
- ❌ 缺乏原因解释 → 只描述数据，不解释背后原因
- ❌ 以通用信息为结论 → 使用前人已经得到的或大家都熟知的信息作为本文的结论
- ❌ 数据没有分析误差 → 有具体数据（特别是实验数据）的论文，误差分析是必要项
- ❌ 重复背景资料 → 显得论文比较啰嗦
- ❌ 情态动词使用错误 → 中英文表达习惯不同

### Checklist（4项）

1. 讲故事以事实为基础、以数据为准绳，用浅显易懂的语言突出科研论文背后所揭示的内容和意义
2. 突出数据分析之后的结论，采用中心句+数据支持的形式，紧扣论文的科学问题
3. 写作方法：先(1)介绍研究结论，再(2)展示数据，然后(3)深化研究，最后(4)阐明研究意义
4. 好的科学故事应该突破数据的限制，更好地阐明数据所代表的结论和意义

### 进阶检查点

- 是否流于数据罗列（实验报告化）？
- 对比数据是否过了实验误差线？
- 是否有深层机制破译？

## 三、结论（Conclusion）

### 要素清单（以说明型结论为例）

- [ ] **研究背景或前人不足**：1-2句话，使读者快速了解研究领域和挑战
- [ ] **主要研究方法**：1句话（如实验或数值模拟等）
- [ ] **主要结论（分主题）**：每个主题2-3句话，分段，简单解释结论背后的原因
- [ ] **重申研究意义**：1-2句话，结合前人研究不足高度概括
- [ ] **未来研究方向**：1-2句话（可选），可结合研究不足引申
- [ ] **列出研究不足**：1-2句话（可选），如实验、理论或模拟的简化假设

### 独立性要求

> 读者单独看结论部分也必须能看懂

- [ ] 包含必要的背景介绍
- [ ] 不使用未定义的缩写词
- [ ] 关键信息不缺失

### 常见错误（毒舌批判靶点）

- ❌ 非独立性 → 缺乏背景介绍、直接使用缩写词、关键信息缺失
- ❌ 重复正文的内容 → 无法升华，造成结论的片面性或局限性
- ❌ 格式不明确 → 建议分主题分段或使用项目符号
- ❌ 过多的重复背景资料 → 冲淡论文的主要观点
- ❌ 复杂而冗长 → 需做到条理清楚且精炼简洁
- ❌ 引用文献 → 一般不建议在结论中引用
- ❌ 道歉体 → "能力有限"等道歉 → 应以"局限性"方式呈现
- ❌ 非数据支持的新结论 → 提出本文数据无法支持的新结论或通用结论
- ❌ 多观点没有重点 → 介绍一切涉猎到的观点并列举表达

## 四、引言（Introduction）

### 核心要求

> 课件中无单独引言章节，以下内容整合自**天巍录音**中的"如何介绍他人工作"技巧

### 评价他人工作的核心原则

**"一本正经的吹" + "不露痕迹的黑"**

#### 吹的技巧（正面评价他人工作）

- [ ] **详细评价**：避免简单罗列，对每个重要工作详细评价——谁提出了什么方法？什么模型？解决了什么问题？
- [ ] **使用修饰词拔高**：new, novel, firstly, greatly, effective, important
- [ ] **篇幅差异对待**：对领域大牛/核心开创者用较多篇幅评述；非重要文献可多篇一起综述
- [ ] **"讨好"的目的**：领域内核心开创者和牛人的工作一定要看全、评价到位，审稿人可能就是他们

#### 黑的技巧（委婉指出前人研究不足）

- [ ] **委婉**：不露痕迹地指出不足，不得罪被你"黑"的人
- [ ] 万一审稿人就是被你批评的人，语气不当会导致审稿迟迟不返回

### 引言要素检查

- [ ] 研究背景是否清楚交代
- [ ] 前人研究不足是否与后文的创新点完美呼应（创新映射表）
- [ ] 对领域大牛的评价是否到位
- [ ] 是否避免流水账罗列
- [ ] "研究不足"→"本文目的"的逻辑链是否完整

## 五、摘要/标题/关键词（Frontmatter）

### 标题检查

#### 标题要素
- [ ] **高度概括性**：是否涵盖了核心方法和创新点
- [ ] **新奇有趣**：避免让人有"做烂了"的感觉
- [ ] **表明观点**（社科类尤甚）
- [ ] **重要关键词**：与摘要/关键词中的同义词做区分
- [ ] **简洁明了**：能简则简

#### 标题常见问题
- ❌ **标题党**：学术论文不能有"震惊！""竟然"等标题党表达
- ❌ **过早暴露答案**：让审稿人一看标题就知道你用的是什么方法、得出什么结论，失去阅读兴趣
- ❌ **起得太差**：让人没有读下去的欲望
- ❌ **不符合期刊要求**：投稿前未看期刊对标题的具体规定（如 Nature 要求不超过75个字符）

#### 标题的理想状态
> 让审稿人"似懂非懂、想看又不想看"——好像大家都做过，又好像你有点创新，不得不往下看

### 摘要5要素检查
- [ ] **背景**：研究背景
- [ ] **目的**：研究目的/范围
- [ ] **方法**：主要方法
- [ ] **主要发现**：关键结果
- [ ] **展望**：研究意义/展望
- 摘要要求：**独立性**——单独阅读也能理解全文

### 关键词检查
- [ ] 与标题互补（不要重复标题中的词）
- [ ] 提供单含义的短语用于检索

---

## 六、致谢（Acknowledgments）

### 要素检查
- [ ] 资助、支持或协助完成研究工作和提供便利的组织/企业/个人
- [ ] 对研究工作提出建议、指导和帮助的个人
- [ ] 同意转载、引用资料/图片/文献/研究思想和设想的所有者
- [ ] 其他应该感谢的组织和个人

---

## 七、参考文献（References）

### 检查要点
- [ ] 引用数量是否合理（参考目标期刊影响因子：影响因子是多少就引用几个，一般在18个以内）
- [ ] 是否引用了投稿期刊的文献
- [ ] 格式是否符合目标期刊要求（对照国标 GBT 7713-2026）
- [ ] 引用是否在18个月内（时效性）

---

## 附：整体论文检查

### 写作顺序验证
老师推荐的写作顺序：
> 先搭框架（目录）→ 画完所有图表 → 方法论 → 结果讨论 → 结论 → 引言 → 摘要/标题/关键词 → 参考文献

审稿时反向验证该逻辑链是否自洽。

### 创新点检查
- 是否属于以下创新类型之一：
  - 原始创新（发现新问题，提出新方法）
  - 新瓶装旧酒/旧瓶装新酒
  - 移花接木（跨领域方法借用）
  - 批判式创新 / 借鉴式创新 / 集成式创新

### 学术道德红线
- 同样的数据发表不同的论文？
- 类似方法处理同一个问题（灌水）？
- 擅自修改数据？
- 一稿多投？
- 互相挂名？
- 引用不标注？
