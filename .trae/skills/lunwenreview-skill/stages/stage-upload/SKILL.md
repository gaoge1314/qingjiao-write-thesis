# stage-upload — 论文上传与章节拆分子技能

## 1. 当前目标

用户上传完整论文 → AI 自动按章节拆分 → 逐章展示给用户逐一确认 → 确认后写入缓存，告知主技能可推进审稿。

## 2. 主要矛盾

用户上传的论文可能格式不规范、章节标题不标准、段落归属模糊，AI 需要准确识别各章节边界并让用户低成本验证/修正，确保后续审稿不跑偏。

## 3. 要素清单

| 要素 | 说明 |
|------|------|
| 上传接收 | 接收用户上传的完整论文文本（支持 .docx / .pdf / 直接粘贴） |
| 自动拆分 | 按以下章节顺序自动拆分：方法论、结果与讨论、结论、引言、摘要/标题/关键词、致谢/参考文献 |
| 逐章确认 | 每拆完一章展示给用户："这是你论文的【方法论】章节吗？我拆得对吗？" |
| 用户修正 | 用户可对拆分结果进行修正（边界调整、章节合并/拆分） |
| 缓存写入 | 确认完成后将拆分结果写入 workspace/review-comments/chapter-split.md |
| 通知主技能 | 告知主技能：章节确认完成 → 可推进到方法论审稿 |

## 4. 常见错误

- ❌ 将"致谢"错误归入"结论"——结论以参考文献结束，致谢通常在参考文献之后
- ❌ 将方法论的子标题（如 2.1 Experimental Setup）误判为结果讨论章节
- ❌ 未识别中英文混排论文中的章节切换（部分章节中文写、部分英文写）
- ❌ 摘要和关键词拆在一起但未明确区分边界
- ❌ 用户修正后未更新缓存文件，导致后续审稿读到旧数据

## 5. 进阶办法

- 支持用户直接上传文件格式（.docx / .pdf），AI 自动解析文本
- 对格式不规范的论文，允许用户在确认环节一次性调整所有章节的归属
- 章节拆分完成后，自动给出一份"章节结构概览"，让用户从整体上确认架构完整性

## 6. 指导操作

### 步骤 1：接收论文

当主技能调用时，提示用户上传完整论文：

> 请上传你的完整论文（支持粘贴全文文本、上传 .docx 或 .pdf 文件）。

### 步骤 2：自动拆分

AI 按以下章节关键词识别边界并进行拆分：

| 章节 | 识别依据 |
|------|---------|
| 方法论 | Methodology / 研究方法 / 实验方法 / 模型建立 |
| 结果与讨论 | Results and Discussion / 结果与讨论 / 结果与分析 |
| 结论 | Conclusion / 结论 / 总结 |
| 引言 | Introduction / 引言 / 前言 |
| 摘要/标题/关键词 | Abstract / 摘要 + Title / 标题 + Keywords / 关键词 |
| 致谢/参考文献 | Acknowledgments / 致谢 + References / 参考文献 |

### 步骤 3：逐章确认

对每个拆分后的章节，依次向用户展示：

> 这是你论文的【方法论】章节吗？我拆得对吗？
>
> （展示章节内容前 200 字 + 末尾 100 字，让用户快速判断边界）
>
> ✅ 正确 → 💬 需要调整（告诉我正确的边界）

用户可选：
- ✅ **正确**：确认该章节拆分无误
- 💬 **需要调整**：提供正确的边界描述，AI 重新切割

依次完成全部 6 个章节的确认。

### 步骤 4：写入缓存

所有章节确认完毕后，将拆分结果写入 `workspace/review-comments/chapter-split.md`，格式如下：

```markdown
# chapter-split.md — 论文章节拆分结果

确认时间：YYYY-MM-DD HH:MM

## 章节列表

1. **方法论**（Methodology）
   - 起始位置：第 X 行 / "xxx" 开头
   - 结束位置：第 Y 行 / "xxx" 结尾
   - 用户确认状态：✅

2. **结果与讨论**（Results and Discussion）
   - 起始位置：...
   - 结束位置：...
   - 用户确认状态：✅

...

## 用户修正记录

- [如有修正] 原拆分边界 xxx → 用户调整为 xxx
```

### 步骤 5：通知主技能

告知主技能：

> 章节确认已完成。拆分结果已保存至 `workspace/review-comments/chapter-split.md`。
> 可推进到方法论审稿（stage-review-methodology）。

## 7. 与其他阶段的关系

| 方向 | 关系 |
|------|------|
| **上游** | 由主技能（lunwenreview-skill）在首次审稿时调用 |
| **依赖** | 需要用户提供完整论文文本/文件 |
| **输出** | 写入 `workspace/review-comments/chapter-split.md` |
| **下游** | stage-review-methodology 读取该文件获取方法论章节内容 |
| **顺序** | 必须最先执行，所有审稿阶段的前置条件 |

## 8. 环节验收

- ☑️ 用户已完成上传
- ☑️ 所有6个章节均已展示给用户并得到确认/修正
- ☑️ `chapter-split.md` 已成功写入 workspace
- ☑️ 主技能已收到通知，可推进至方法论审稿
